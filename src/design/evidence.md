# Evidence Log: Nothing-Inspired Web Design System

## Scope
This design layer is **Nothing-inspired** and **evidence-based**.  
It is **not** presented as an official Nothing web SDK.

## Evidence-based signals
The system is based on publicly observable and officially referenced Nothing product-language signals:

- Nothing uses the terms **Nothing DNA** and **Dot Engine** in product/OS positioning.
- Nothing emphasizes **bespoke animations, icons and fonts**.
- Nothing highlights **widgets**, **Shared Widgets**, and functional customization tied to system utility surfaces.
- Nothing references **Ndot 55** as a named display-style reference.
- Nothing Playground / Essential Apps suggests a real ecosystem direction around compact, utility-first, glanceable experiences.

## Evidence-based visual characteristics
From official Nothing product/OS direction and user-provided references, the following characteristics are safe to use:

- black-first visual environment
- selective white utility cards
- sparse red accent for active, recording, warning, limit, destructive emphasis
- modular tile composition
- circles, pills, rounded squares, soft rectangles
- dot-matrix-like display numerals for clocks, counters, dates, progress
- clean, readable sans-serif for regular interface text
- low-noise iconography
- widget-like glanceable hierarchy

## Inferred web adaptations
The following are implementation choices for web and should not be described as official Nothing specifications:

## Usage policy
All future UI work should:
- honor the evidence-based signals above
